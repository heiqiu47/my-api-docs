# API使用教程

这里整理了常见 AI 客户端平台的 API 接入教程。

## 平台列表

- [酒馆 (SillyTavern)](./sillytavern) — 本地运行的角色扮演聊天前端
- [ChatBox](./chatbox) — 开源跨平台 AI 桌面客户端
- [CC Switch](./cc-switch) — 多 API 配置一键切换工具
- [Cherry Studio](./cherry-studio) — 功能丰富的 AI 桌面客户端（PC 端推荐）
- [RikkaHub](./rikkahub) — 手机端 AI 客户端（安卓端推荐）

## 说明

教程内容会持续补充。如果遇到问题或有想看的平台，欢迎反馈。
